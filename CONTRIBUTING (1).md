# Contributing to the Project

Thank you for your interest in contributing to this Python student project!

## 1. How to Report an Issue

If you find a problem:

1. Open the project's **Issues** section.
2. Click **New Issue**.
3. Clearly describe the problem.
4. Add any useful details about the issue.

## 2. How to Suggest a Feature

To suggest a new feature:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Describe the feature you would like to add.
4. Explain how the feature could improve the project.

## 3. How to Create a Branch

Create a new branch before making changes:

```bash
git checkout -b feature-name
```

Use a clear and meaningful branch name.

## 4. How to Make Changes

1. Open the project in your code editor.
2. Make the required changes.
3. Save your files.
4. Review your changes before committing.

Then commit your changes:

```bash
git add .
git commit -m "Describe your changes"
```

## 5. How to Test Changes

Run the Python program and check that it works correctly.

Make sure:

- The program runs without errors.
- The changes work as expected.
- Existing functionality is not unnecessarily changed.

## 6. How to Create a Pull Request

After making and testing your changes:

1. Push your branch to GitHub:

```bash
git push origin feature-name
```

2. Open the project on GitHub.
3. Click **Compare & pull request**.
4. Describe your changes.
5. Submit the pull request for review.

## 7. Basic Coding Guidelines

- Write simple and readable Python code.
- Use meaningful variable names.
- Keep the code organized.
- Add comments when necessary.
- Avoid unnecessary code.
- Test your changes before submitting a pull request.
